# d1s4 Skin Studio

Закрытая галерея скинов Minecraft: образы в нескольких палитрах, 3D-просмотр, скачивание PNG.

**Сайт:** https://letmesh0w.github.io/d1s4-skins/

Скинов в этом репозитории нет. Они лежат зашифрованными в приватном репозитории `d1s4-skins-data`;
сайт скачивает их по токену GitHub и расшифровывает паролем прямо в браузере.

## Как устроен вход

- **Токен** (fine-grained, только чтение Contents у `d1s4-skins-data`): без него GitHub не отдаёт файлы.
- **Пароль**: файлы зашифрованы AES-256-GCM, ключ выводится из пароля через PBKDF2-SHA256 (600 000 итераций).
- На устройстве ничего не сохраняется: токен, ключ и расшифрованные скины живут только в памяти открытой вкладки. Через 10 минут без действий галерея запирается.
- После трёх неверных попыток подряд включается растущая пауза.
- Страница запрещает чужие скрипты (Content-Security-Policy), сеть разрешена только к api.github.com, работа во встроенной рамке отключена.

## Что внутри

```
index.html              страница
css/style.css           стили
js/app.js               интерфейс
js/vault.js             вход, загрузка и расшифровка
js/guard.js             паузы после неверных попыток
vendor/skinview3d…      3D-просмотр (skinview3d 3.0.1)
```

## Управление

- Категории слева, палитры сверху; `/` — поиск, Esc — закрыть окно, ← → — листать образы в окне.
- Наведение на карточку включает 3D, щелчок открывает образ: модель можно крутить мышью.
- Ссылка запоминает палитру, категорию и открытый образ (`#pal=navy&cat=coats&look=…`), избранное хранится в браузере.

## Запуск локально

```
python3 -m http.server 8000
```
